USB FORMAT
FORMAT · BACKUP · ENCRYPTION — ExFAT WORKS ON ALL SYSTEMS
Why ExFAT? ExFAT is the only filesystem natively readable/writable on macOS, Linux and Windows — no drivers needed. FAT32 has a 4 GB per-file limit (too small for ISOs). NTFS is read-only on macOS by default. Recommendation: ExFAT for all sticks >32 GB, FAT32 only as fallback if ExFAT tools are missing.
Format — macOS
macOS — diskutil
# Step 1: Find stick
diskutil list
# Look for: /dev/disk2 (external, physical)
# ⚠ ALWAYS verify disk number — never use disk0 (system)!

# Step 2: Format entire stick (including partition table)
diskutil eraseDisk ExFAT HACKUSB /dev/disk2
# → Mounts at: /Volumes/HACKUSB

# Alternatively: Format only one partition
diskutil eraseVolume ExFAT HACKUSB /dev/disk2s1

# Safe eject
diskutil eject /dev/disk2
Format — Linux
Linux — lsblk + mkfs
# Step 1: Find stick
lsblk -o NAME,SIZE,TYPE,MOUNTPOINT,LABEL
# Output: sdb  14.9G disk  ← that's the stick
# ⚠ NEVER use sda — that's the system drive!

# Step 2: Unmount
sudo umount /dev/sdb1

# Step 3: Install ExFAT tools
sudo apt install exfatprogs          # Ubuntu 22.04+
sudo apt install exfat-fuse exfat-utils  # older Ubuntu
sudo pacman -S exfatprogs            # Arch/Manjaro

# Step 4: Format
sudo mkfs.exfat -n "HACKUSB" /dev/sdb1
# Fallback (no exfat available):
sudo mkfs.vfat -F 32 -n "HACKUSB" /dev/sdb1

# Step 5: Mount
sudo mkdir -p /media/$USER/HACKUSB
sudo mount /dev/sdb1 /media/$USER/HACKUSB

AD BLOCK
HAGEZI DNS BLOCKLISTS — ADS · TRACKING · MALWARE · PHISHING
Enable via: sudo zsh 13_adblocker/setup_adblocker.zsh — works on macOS, Linux, and Windows WSL2
How it works: Adds ~100K+ domains to /etc/hosts pointing to 0.0.0.0. Every DNS lookup for a blocked domain returns nothing — no request reaches the ad/tracker/malware server. Works system-wide, offline, in any browser or app. Source: Hagezi DNS Blocklists — most accurate maintained blocklists available.

ENCRYPT
VERACRYPT AES-256 VAULT — SSH KEYS · CREDENTIALS · REPORTS
What the vault is: A single encrypted file (secrets.vc) on the stick — like a USB within a USB. Mount = normal folder. Unmount = secure encrypted file. AES-256-XTS + SHA-512 key derivation. Without the password: unbreakable for thousands of years.

# Check status
zsh /Volumes/HACKUSB/14_vault/vault.zsh status

# Close securely (ALWAYS before removing stick!)
zsh /Volumes/HACKUSB/14_vault/vault.zsh unmount

MERGE CONFLICTS

If git pull --ff-only fails (local changes) → auto git reset --hard origin/main. Custom files in tool folders could be overwritten. Always put your own scripts in 08_scripts/ or in the Vault.

BLOCKLIST QUALITY

Each downloaded blocklist is checked for >1000 entries. If download fails (no internet, server down) → file is discarded, old version is kept. No data loss.

INTERNET REQUIRED

Checks connection to github.com first. Without internet: clean abort. Offline: manually cd 01_recon/theHarvester && git pull in each tool directory.

CRONJOB

Monthly cronjob (1st of every month, 03:00) offered in setup wizard. Log goes to update.log and .last_update on stick. View: crontab -l | grep hackusb.
